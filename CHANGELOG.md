# Changelog

All notable changes to LexiNote are documented here. This project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-09-19

### Added

- Local-first vocabulary sets with filtering and offline persistence.
- Fast English definitions, IPA, parts of speech, and translations.
- Pronunciation through dictionary audio or the system English voice.
- Light and dark borderless interface.
- System tray, global shortcut, theme, and Windows startup controls.
- Retry action for previously saved words with missing dictionary details.
- Automatic cleanup of translation-provider formatting markers in new and saved words.
- Automated Windows EXE/MSI releases with SHA-256 checksums.
